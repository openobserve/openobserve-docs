# LLM Provider Observability Integrations

OpenObserve can trace each call your app makes to an LLM provider. For every request, it records token usage (prompt, completion, total), latency, model name, and error details. Use this data to track cost, speed, and errors across all the providers your app uses.

Each guide uses an OpenInference or OpenTelemetry instrumentor for that provider's SDK. The instrumentor sends traces straight to OpenObserve.
