description: "The Config sidebar customizes OpenObserve dashboard panel behavior, layout, and appearance through collapsible sections for legend, data, axis, labels, and more."
---

The Config sidebar in OpenObserve dashboards allows users to customize the behavior, layout, and appearance of individual panels.

In the panel editor, select **Config** to open the configuration sidebar. It is organized into collapsible sections (General, Legend, Data, Axis, Labels, and more), and the sections shown depend on the selected chart type. All sections start collapsed. Use the **Search config** bar at the top to filter settings by name, and the expand and collapse toggle next to it to open or close all sections at once.
